WHAT WAS FIXED
--------------
Connecting a real sheet failed because a gid in the pasted URL
(...edit?gid=457366843) replaced the tab name in the request. A gid from the
address bar is just whichever tab was open, so the dashboard asked for the
wrong tab and never mentioned "Business Working Account" at all.

Now: the tab is requested BY NAME first; the gid is only a fallback.

Also, the layout was read at fixed row numbers. Google's gviz endpoint can
drop leading blank rows, shifting everything. The week-date row is now found
by content and all other rows are read as offsets from it — so the sheet
still parses if rows shift, or if you insert a row above row 6.

If a connection still fails, the error now lists every endpoint tried and
what each one said. Send me that text and it will point straight at the cause.
